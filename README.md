# Marketing Campaign Analysis 📊

## Problem Scenario
The marketing mix is a widely utilized concept in the execution of marketing strategies, focusing on the four Ps of marketing: product, price, place, and promotion.[cite: 1] This project involves Exploratory Data Analysis (EDA) and Hypothesis Testing to enhance comprehension of the diverse factors influencing customer acquisition and purchasing behavior.[cite: 1]

## Files in this Repository
* `marketing_data.csv`: The dataset containing variables related to the Four Ps of Marketing. 
* `1739524800_marketing_campaign_problem_statement.docx`: The official project requirement and objective document.
* `project_file.ipynb`: The Jupyter Notebook containing the Python code for data cleaning, visualization, and hypothesis testing.

## Objectives & Steps Performed
* **Data Cleaning & Imputation**: Handled missing income values based on education and marital status.[cite: 1, 2]
* **Feature Engineering**: Created new variables for total children, age, total spending, and total online purchases.[cite: 1, 2]
* **Data Encoding**: Applied one-hot encoding for categorical variables (Marital Status).[cite: 1, 2]
* **Exploratory Data Analysis**: Visualized correlations and identified top-performing products (Wines) and lowest revenue products (Fruits).[cite: 1, 2]
* **Hypothesis Testing (SciPy)**:
  1. Older individuals vs. traditional in-store shopping.[cite: 1, 2]
  2. Customers with children vs. online shopping preferences.[cite: 1, 2]
  3. Store sales vs. alternative distribution channels (Cannibalization effect).[cite: 1, 2]
  4. US vs. Rest of the World total purchase volume comparisons.[cite: 1, 2]
