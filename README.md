# Marketing Campaign Analysis 📊

## Problem Scenario
The marketing mix is a widely utilized concept in the execution of marketing strategies, focusing on the four Ps of marketing: product, price, place, and promotion. This project involves Exploratory Data Analysis (EDA) and Hypothesis Testing to enhance comprehension of the diverse factors influencing customer acquisition and purchasing behavior.

## Files in this Repository
* `marketing_data.csv`: The dataset containing variables related to the Four Ps of Marketing. 
* `1739524800_marketing_campaign_problem_statement.docx`: The official project requirement and objective document.
* `project 2.ipynb`: The Jupyter Notebook containing the Python code for data cleaning, visualization, and hypothesis testing.

## Objectives & Steps Performed
* **Data Cleaning & Imputation**: Handled missing income values based on education and marital status.
* **Feature Engineering**: Created new variables for total children, age, total spending, and total online purchases.
* **Data Encoding**: Applied one-hot encoding for categorical variables (Marital Status).
* **Exploratory Data Analysis**: Visualized correlations and identified top-performing products (Wines) and lowest revenue products (Fruits).
* **Hypothesis Testing (SciPy)**:
  1. Older individuals vs. traditional in-store shopping.
  2. Customers with children vs. online shopping preferences.
  3. Store sales vs. alternative distribution channels (Cannibalization effect).
  4. US vs. Rest of the World total purchase volume comparisons.

## Technologies Used
* Python (Pandas, NumPy)
* Matplotlib & Seaborn (Data Visualization)
* SciPy (Hypothesis Testing)
* Scikit-Learn (Data Preprocessing)
